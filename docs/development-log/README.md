# Development log

This folder records how SideQuest T&T is built, including decisions, experiments, results, and changes in direction. Logs support reproducibility and the project write-up, including the experiment of using GitHub Copilot to build a product whose player-facing AI is Gemma.

## Format

Create one numbered Markdown file for each meaningful work session or milestone, for example `002-first-vertical-slice.md`. Keep entries factual and concise. Separate what was planned from what was actually done; record the tools and prompts or approaches that mattered, outcomes, problems, decisions, and the next step. Do not claim a feature works unless it was verified, and do not fill gaps with guesses. Link relevant code, commits, screenshots, or saved agent sessions when available.
